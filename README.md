# Taralytix — Student Performance Prediction System

Taralytix is a student performance prediction system developed as a Data Science project.

The system uses academic data and machine learning to help predict student performance and provide useful academic insights.

## Project Overview

Taralytix was developed to explore how data science and machine learning can be applied to student academic records.

The system works with information such as:

- Attendance
- CAT marks
- Assignment marks
- Exam marks
- Total marks
- Grades
- Course information
- Semester information

## Main Features

- Student registration and login
- Student academic record management
- Student performance prediction
- Academic data analysis
- Graphical analysis of performance
- Semester-based performance information
- System reports
- SQLite database integration

## Technologies Used

- Python
- Tkinter
- SQLite
- Machine Learning
- Data Analysis
- Data Visualization

## Project Structure

The main Python source code for the system is contained in:

`Taralytix.py`
